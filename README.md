# Lead Processor (Yandex Mail → Telegram)

## Что делает
- Подключается к Яндекс.Почте по IMAP
- Автоматически забирает непрочитанные письма
- Парсит лид из текста письма
- Определяет адрес по ключевым словам
- Отправляет в нужный Telegram-чат

## Запуск локально
1. Установить зависимости
   - `npm install`
2. Создать `.env` по шаблону `.env.example`
3. Запустить
   - `npm start`

## Деплой в Render
1. Создать новый Web Service
2. Подключить GitHub репозиторий с этой папкой
3. Build Command: `npm install`
4. Start Command: `npm start`
5. В разделе Environment добавить переменные из `.env.example`

## Яндекс.Почта
- Используйте пароль приложения для IMAP
- Убедитесь, что IMAP доступ включен в настройках аккаунта

## Формат письма
Ожидается текст вида:
```
Поступил входящий звонок

Телефон: 79267982346
Запись диалог: https://mezit.ru/sound/2025/11/27/227aa0936a5eea5ce11da311577656a0.wav
Дата оповещения 27.10.2025 09:54

Резюме диалога:
Имя гостя: Не указано
Адрес: Не указано
Сколько человек: Не указано
Дата и время: Пятница 28.11.2025 13:09
Зал: Не указано
Дополнительные комментарии: Гость интересуется пиццей пепперони.
```

## Логика определения адреса
- `Шоссей...` → Шоссейная
- `Краснококш...` → Краснококшайская
- `Меред...` / `Меридиан...` → Мередианная
- Если не найдено — Мередианная
